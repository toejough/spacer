# 026 — Don't pause on clear errors

**Status:** open
**Type:** convention

## Context

From retro #018: when a build or test fails with an obvious cause (e.g., Vitest picking up Playwright's `test.describe`), diagnose and fix in the same turn. Don't stop and wait for input when the error is self-explanatory.
