# 027 — Project identity claims must be backed by infrastructure

**Status:** open
**Type:** convention

## Context

From retro #018: Spacer was called "Spacer PWA" from day one but had zero PWA infrastructure through two full bootstraps. If the project identity includes a capability (PWA, offline-first, etc.), the bootstrap increment must include minimum plumbing for that capability. A label without infrastructure is a lie.
