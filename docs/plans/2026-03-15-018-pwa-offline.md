# PWA Offline Support (#018)

**Date:** 2026-03-15
**Issue:** docs/issues/018-pwa-not-working-offline.md

## Problem

Spacer claims to be a PWA but has zero offline infrastructure. Two concrete bugs:

1. **Offline navigation fails silently:** With the server stopped, clicking a deck does nothing. Route chunks are lazy-loaded (`() => import("./views/...")` in `main.ts`), so the browser tries to fetch the JS chunk, fails, and silently swallows the error.
2. **Offline refresh kills the app:** Refreshing the page with the server stopped returns a network error. There's no service worker to serve cached `index.html`.

## Solution

Add `vite-plugin-pwa` with Workbox `generateSW` strategy to precache all build assets.

### Why `vite-plugin-pwa` + `generateSW`

- Standard tooling for Vite apps — handles manifest generation, SW generation, and precaching
- `generateSW` (not `injectManifest`) because we need no custom SW logic, just precaching
- All build assets precached automatically — the app is small enough to cache everything
- Lazy route chunks are included in the precache manifest, so offline navigation works

### E2E Tests (Playwright)

Tests must run against a **production build** — service workers don't activate in Vite dev mode.

**Setup:**
- `playwright.config.ts` configures `webServer` to build and serve the prod bundle
- Each test loads the app, waits for the SW to install and activate, then goes offline

**Test 1 — Offline navigation:**
1. Load app at `/`
2. Create a deck (so there's something to click)
3. Wait for SW to be ready
4. Go offline via `context.setOffline(true)`
5. Click the deck link
6. Assert `DeckView` renders (deck name visible, add-card form present)

**Test 2 — Offline refresh:**
1. Load app at `/`
2. Wait for SW to be ready
3. Go offline via `context.setOffline(true)`
4. Refresh the page (`page.reload()`)
5. Assert app renders (header visible, page functional)

### PWA Config

```ts
// vite.config.ts — VitePWA plugin options
VitePWA({
  registerType: "autoUpdate",
  manifest: {
    name: "Spacer",
    short_name: "Spacer",
    description: "Spaced repetition flashcards",
    theme_color: "#4f46e5", // indigo-600
    background_color: "#f9fafb", // gray-50
    display: "standalone",
    icons: [
      { src: "icon-192.png", sizes: "192x192", type: "image/png" },
      { src: "icon-512.png", sizes: "512x512", type: "image/png" },
    ],
  },
  workbox: {
    globPatterns: ["**/*.{js,css,html,ico,png,svg,woff2}"],
  },
})
```

### What this does NOT cover

- Custom offline fallback page (not needed — all routes are precached)
- Background sync (no server to sync with)
- Push notifications
- Sophisticated cache strategies for API calls (no API)
- Production-quality icons (placeholder only)
